# Contributing

Run the commands in the README from the repository root using a virtual environment.
Keep example inputs separate from generated outputs and personal records. Preserve
existing attribution and describe AI assistance when it materially contributed.

Before proposing a change, run `python -m unittest discover -s tests -v`.
Include the problem, resulting behavior and checks performed in the pull request.
Report a reproducible defect with the command used, Python version and a small
fictional input. Do not upload credentials or personal records in an issue.
